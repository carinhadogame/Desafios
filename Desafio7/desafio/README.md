# Desafio 7: Sistema Linear 3x3

Este diretório contém a solução do Desafio 7. O script em Python resolve um sistema de equações 3x3 a partir de valores inseridos pelo usuário no terminal, com verificação de determinante nulo.


## Dependências
O código utiliza a biblioteca NumPy. Para instalar, rode no terminal:
`pip install numpy`

## Como executar
Acesse a pasta raiz do desafio e execute o arquivo:
`python src/main.py`
