# Exercícios Práticos: Sistemas Lineares

Resolução dos quatro exercícios de modelagem matricial. Os códigos foram implementados em Python usando o NumPy para as operações de álgebra linear.



## Arquivos (pasta src/)
* `exercicio1.py`
* `exercicio2.py`
* `exercicio3.py`
* `exercicio4.py`

## Dependências
É necessário ter o NumPy instalado na máquina para rodar os scripts:
`pip install numpy`

## Como executar
Execute o script correspondente a cada exercício no terminal. Exemplo:
`python src/exercicio1.py`
