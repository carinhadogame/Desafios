# Sistema de Vendas em Python

Este projeto é um sistema simples feito em Python para gerenciar produtos e vendas.

## Funcionalidades

* Cadastrar produtos com nome, preço e estoque
* Realizar vendas com controle de estoque
* Aplicar desconto de 5% para compras acima de 10 unidades
* Gerar relatório com todas as vendas e total arrecadado

## Como executar

1. Abra o arquivo principal no VSCode
2. Execute o código
3. Use o menu para navegar entre as opções

## Objetivo

Praticar listas, dicionários, funções e estruturas de repetição em Python.
