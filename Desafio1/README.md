# Projeto: Sistema de Folha de Pagamento

Esse programa foi desenvolvido para gerenciar o pagamento de uma pequena empresa, calculando salários e descontos de forma automática.

## O que o sistema faz:
* **Cadastro:** Aceita funcionários do tipo Estagiário, CLT e Freelancer.
* **Cálculos Automáticos:** Aplica as regras de INSS e IRRF dependendo do tipo de contrato e do valor do salário.
* **Relatórios:** Mostra os detalhes na tela e gera um arquivo `relatorio_folha.txt` com tudo organizado.
* **Validação:** O código trata erros de entrada (como digitar letras onde deveria ser número) para não travar.

## Como rodar o projeto:
1.  Abra o terminal na pasta raiz do projeto.
2.  Execute o comando: `python src/main.py`
3.  Use as opções do menu (1 a 4) para navegar.
